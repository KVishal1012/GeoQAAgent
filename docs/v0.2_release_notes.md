# GeoQA Agent V0.2 Release Notes

## Theme

V0.2 adds an evidence-backed AI report layer on top of the deterministic GeoQA engine.

The deterministic QA artifacts remain the source of truth. The AI layer generates a draft report using only:

- `summary.json`
- `issues.csv`
- `run_record.json`
- retrieved fix playbook text

## New Capabilities

- OpenAI-first LLM gateway
- Fake/static gateway for tests
- Prompt registry
- Local RAG fix playbooks
- Agent report draft generation
- Report consistency validation
- Hallucination monitoring
- Human review workflow with `draft_ready`, `blocked`, `rejected`, and `approved` states
- Final report generation only after approval
- Minimal Streamlit interface
- Existing-draft review through CLI or Streamlit without regenerating the run

## New Artifacts

- `agent_report_draft.md`
- `agent_report.json`
- `report_consistency.json`
- `hallucination_check.json`
- `review_status.json`
- `agent_report.md` after approval only

## Product Claim

GeoQA produces evidence-backed AI reports, not free-form AI summaries.
